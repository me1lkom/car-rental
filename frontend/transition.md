# Карта переходов VELA

Главная (/)
  → карточка машины (/cars/:id)
    → оформление заявки (/booking/:id) — только если вошёл
      → подтверждение (/done)
        → кабинет (/account)
  → вход (/login) или регистрация (/register)
    → кабинет (/account)
  → кабинет (/account) — только если вошёл
    → выход → вход

Админ (/admin) — только manager или admin
  → машины / заявки / пользователи (пользователи только admin)

Отказ в доступе:
- не вошёл и открыл /account, /booking, /admin → редирект на /login
- вошёл как client и открыл /admin → сообщение и редирект на главную
